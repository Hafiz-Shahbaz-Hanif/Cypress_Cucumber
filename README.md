An end-to-end test framework built with **Cypress** and **Cucumber** (`@badeball/cypress-cucumber-preprocessor`),
on the **Page Object Model**, covering both a **web UI** and a **REST API**.

| | |
|---|---|
| **UI under test** | [SauceDemo](https://www.saucedemo.com) |
| **API under test** | [restful-booker](https://restful-booker.herokuapp.com) via `cy.request` |
| **BDD** | Gherkin `.feature` files + JavaScript step definitions |
| **Design** | Page Object Model (`cypress/pages/`) |
| **Bundler** | esbuild preprocessor |
| **Reporting** | `multiple-cucumber-html-reporter` + Cypress video / screenshots |
| **CI** | GitHub Actions (`cypress-io/github-action`) |

---

## Highlights

- **BDD + POM together.** Feature files describe behaviour; step definitions are
  thin and delegate every interaction to a Page Object.
- **UI + API in one suite.** UI journeys (login, sorting, cart, checkout) plus API
  contract checks with `cy.request` and aliases.
- **Data-driven** via `Scenario Outline` (login permutations, four sort orders).
- **Deterministic runs.** `retries` in run mode, `cy.clearLocalStorage()` between
  scenarios (SauceDemo persists the cart), and app-error suppression scoped to
  the one benign SauceDemo exception.
- **Tag filtering.** `cypress run --env tags=@smoke` (`filterSpecs` + `omitFiltered`).

## Project structure

```
cypress/
├── e2e/
│   ├── features/                # Gherkin specs (login, cart_checkout, api_booking)
│   └── step_definitions/        # one module per feature area
├── pages/                       # Page Object Model (LoginPage, InventoryPage, ...)
├── support/
│   ├── e2e.js
│   └── commands.js              # cross-cutting commands only
└── fixtures/
scripts/report.js                # builds the HTML report from cucumber JSON
cypress.config.js                # cucumber + esbuild wiring
```

## Getting started

```bash
npm ci
npx cypress verify
```

## Running

```bash
npm test                 # headless run, then build the HTML report
npm run test:smoke       # only @smoke scenarios
npm run cy:open          # interactive runner
npx cypress run --spec "cypress/e2e/features/api_booking.feature"
```

## Reports

- **HTML:** `cypress/reports/html/index.html` (generated by `npm run report`)
- **Video / screenshots:** `cypress/videos/`, `cypress/screenshots/`

## CI

`.github/workflows/ci.yml` runs the suite on Chrome via `cypress-io/github-action`, then
builds the HTML report and uploads it with videos and screenshots.
